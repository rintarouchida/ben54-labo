# 08 API共通(エラー形式・日本語化・レート制限)

- 参照: 要件定義書 5.4, 7.4, 7.6, 8.2(共通)
- 時期: 1日目 午後

## 概要
API 全体のエラーレスポンスを5.4節の形式に揃え、メッセージを日本語にし、レート制限をかける。

## 完了条件
- 404 / 422 / 429 / 500 が5.4節の形式で返る
- `APP_DEBUG=false` で500のときスタックトレースを返さず、例外をログに残す
