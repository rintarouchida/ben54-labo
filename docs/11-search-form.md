# 11 検索フォームとURLの条件保持(SCR-01)

- 参照: 要件定義書 F-01〜F-06, F-19, 4.1
- 時期: 2日目 午前

## 概要
都道府県・取扱分野・キーワードの検索フォームを作り、条件を URL のクエリ文字列で保持する。

## 完了条件
- 検索すると URL が変わり、リロード・ブラウザバックでも同じ条件が復元される
