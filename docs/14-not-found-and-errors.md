# 14 404画面・共通エラー表示(SCR-03)

- 参照: 要件定義書 F-16〜F-18, 4章
- 時期: 2日目 午後

## 概要
存在しない URL・弁護士 ID 用の404画面と、500・通信エラーの共通表示を作る。

## 完了条件
- 未定義の URL と存在しない弁護士 ID で404画面が出る
- 500・通信エラーが画面上部に表示される
